📐 Model Architecture & Forecasting Methodology

The 7-day temperature trajectory is projected using a hybrid Harmonic Fourier Decomposition with Synoptic Autoregressive Decay, fitted across all 4,270 historical hourly readings from 2026-04-10 to 2026-10-05 08:00:

2. Macro Seasonal Drift: A second-order polynomial component accounts for seasonal transition (summer to autumn solar elevation changes in Kristiansand).

3. Synoptic Air Mass Persistence (AR Inertia): The current real-time deviation from baseline (+4.35 °C) represents transient pressure systems. This variance decays with an autoregressive half-life of ~48 hours (φh/24 with φ = 0.70), guiding the forecast smoothly back toward the climatological baseline.

4. Project Controlling & EAC Analogy: In project controlling (EAC/ETC forecasting), performance separates baseline planned rhythms from transient cost variances.
