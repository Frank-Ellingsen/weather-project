📐 Model Architecture & Forecasting Methodology

The 7-day temperature trajectory is projected using a hybrid Harmonic Fourier Decomposition with Synoptic Autoregressive Decay, fitted across all 5,025 historical hourly readings from 2026-04-10 to 2026-11-05 19:00:

2. Macro Seasonal Drift: A second-order polynomial component accounts for seasonal transition (summer to autumn solar elevation changes in Kristiansand).

3. Synoptic Air Mass Persistence (AR Inertia): The current real-time deviation from baseline (-0.26 °C) represents transient pressure systems. 4. Project Controlling & EAC Analogy: In project controlling (EAC/ETC forecasting), performance separates baseline planned rhythms from transient cost variances.
